# Map layer sources

`earth-topography-mercator.jpg` is a locally packaged, Web Mercator projection of Natural Earth's **1:50m Cross-blended Hypso with Shaded Relief and Water**, version 3.2.0 (`HYP_50M_SR_W`). It combines elevation-tinted land, shaded relief, and ocean coloring.

Source: <https://www.naturalearthdata.com/downloads/50m-raster-data/50m-cross-blend-hypso/>

Natural Earth raster data is public domain: <https://www.naturalearthdata.com/about/terms-of-use/>.

This is a cartographic image, not an elevation grid. It can be displayed and composited as a map layer, but should not be used as height input for terrain displacement or to derive accurate surface normals.
